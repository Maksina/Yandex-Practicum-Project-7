# Реализация RAG-бота с техниками промптинга

Технологический стек:
- ЯП: Python 3
- LLM: qwen3:4b-instruct
- Эмбеддинги: Qwen3-Embedding-4B  
- Векторная база: ChromaDB  

## Промпты

1. [system_prompt.txt]() - Системный промпт с указание CoT.
2. [few_shot_examples.txt]() - Few-shot

## Реализация

1. [rag_engine.py]() - Ядро сервиса, в котором происходит поиск в векторной базе и обращение к LLM.
2. [rag_bot_ollama.py]() - Консольный интерфейс, который использует rag_engine.py
3. [telegram_bot.py]() - Телеграм бот, который использует rag_engine.py. Необходимо вставить свой токен в скрипт.
